BomberMan - це 2D клітинкова аркадна гра, натхненна класичною серією Bomberman. Ігрове поле побудоване у вигляді двовимірної сітки, де всі персонажі та об’єкти розташовані в окремих клітинках, а рух гравця відбувається дискретно - по одній клітинці за крок. Гравець керує персонажем, розміщує бомби, знищує ворогів і руйнівні блоки, уникаючи вибухів та пасток. Гра реалізована на Python з використанням Pygame та демонструє принципи grid-based gameplay без застосування фізики або безперервного руху.
